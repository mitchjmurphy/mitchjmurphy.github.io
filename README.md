# Mitch Murphy — personal links

A responsive, dark-themed personal landing page for Mitch Murphy. The site brings together social profiles, projects, and useful web tools in one place.

## What's on the page

- **Around the web:** GitHub, LinkedIn, Instagram, X, Strava, Spotify, and a WHOOP referral link.
- **Projects & work:** A link to browse GitHub repositories.
- **Useful little tools:** DevDocs and Excalidraw.

## Implementation

The site is a static HTML page in [`index.html`](./index.html), with its styles included in the page. It can be hosted directly with GitHub Pages; no build step or framework is required.

The portrait image is used in the topbar and as a blended intro background. Browser and Apple touch icons are provided by `favicon.ico`, `favicon-32.png`, and `apple-touch-icon.png`.
